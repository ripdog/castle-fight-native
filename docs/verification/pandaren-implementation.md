# Pandaren implementation

Retained Castle Fight 9.27/r1 extraction tree: `8ea806dca331ff254995e94e6f0baf225a14bf10`. Builder `X07P`, registration `WK`, and the resolved `ubpx`/`ubpy` build-card coordinates define implementation order (an absent coordinate on a map-authored `npgr`/`hgtw`/`hhou` building is the stock origin). Complete each root and its entire upgrade chain before moving right, then the next row. Only completed entities become buildable. The order is Bamboo Dojo → Sagepaw Sanctum; Brew Hut → Fighting Tavern → Temple of Ten Thousand Drinks; Temple of the Wandering Spark; Pandaren Siege Workshop; Cloud Hangar; Jade Shrine; Withering Hall; Thunderpaw Spire; Poof Tower (already promoted as a shared tower); Celestial Chi Tower.

## Bamboo Dojo / Sagepaw Monk

- Identity/source: runtime r175; `n03D` (`npgr`) produces `n03E` in the top-left slot and upgrades to the Sagepaw Sanctum. Protected life, armor, movement, attack damage/dice/cooldown/range and the Monk's mana pool supersede static sentinels; the ordinary Magic missile weapon targets ground, air and structures and the second weapon is disabled. Corpse (raisable, decaying organic), collision, classification, production, construction/repair/economy and upgrade data consume the retained catalogs.
- Complete inventory/control flow: the only ability is `A0GN` (`Ahea`, "PAN: Panda Monk Heal"). `NI` registers it with target mode 7 (any ally) and the closure `MonkHeal` — the same autonomous native Heal order the Faerie Dragon uses, with protected mana and cooldown. Its mask is air/ground friendly organic non-ancient units, vulnerable or invulnerable, self included. No other script grant, proxy or hidden marker exists on this body.
- Scripted spell trace: trigger eligibility — wounded friendly unit within the native Heal range (the shared `WoundedFriendlyUnit` policy). Approach — native cast range. Effect origin — the native heal lands on the target; the script then spawns a free recycled dummy at the *caster* and orders the dummy's `healingspray` (`A0GP`, `ANhs`) at the *healed unit's* position. Effect eligibility is independent of the trigger: the spray's own mask is friendly air/ground units (mechanical and non-organic units included, the caster included), vulnerable only; spell-immune friends are healed. Timing — the caster's attack order resumes 0.1 s after the cast (the retained callback); the spray is a channel on a dummy that is returned after the closure's 2.0 s lifetime, so it outlives the caster. Resources — the parent's mana/cooldown only; the child dummy is protected-free.
- Healing Spray interpretation: the retained fields give wave count, interval, per-wave amount, per-wave total cap and missile count. Native evidence is limited to [the editor note](https://github.com/Cokemonkey11/wc3-ability-doc/blob/main/sources/screwthetrees-wc3-editor-ability-insight-document/2023-11-14.md) that Healing Spray is a Cluster Rockets copy with reversed damage. The engine therefore reuses the Blizzard-wave cadence: every wave heals every eligible unit in the area by the retained amount, the per-wave total is shared proportionally when the retained cap would be exceeded, and the first wave lands one retained interval after the cast. These cadence choices are deterministic interpretations without a Warcraft runtime oracle; the missile count is cosmetic.
- State/serialization: the spray is authoritative `NativeAction::HealingSpray` state (canonical hash tag 40, serde-serialized with the other native actions); the heal profile gained an optional `spray` (hashed). A scripted heal spray is resolved per body, because each body's script casts its own child ability.
- Presentation: no new gameplay-relevant presentation state; heal and spray art remain source-owned. Pandaren becomes selectable with this completed root; later roots and upgrades remain unavailable until their own mechanics are verified.

## Sagepaw Sanctum / Sagepaw Soulkeeper

- Identity/source: runtime r176; `n03S` (`npgr`) upgrades from the Bamboo Dojo and produces `n03T`. Protected life, armor, movement, weapon and mana pool come from the retained catalogs; the weapon, corpse, classification, production and upgrade data are the same classes as the Monk's.
- Complete inventory/control flow: `A0GN` again, registered by `NI` with the second closure (`MonkHeal1`). The native Heal fields are identical to the Monk's; the script's child is `A0HI` ("Healing Spray 2", `ANhs`) with its own retained amount, per-wave cap, missile count and area. The two bodies share one ability rawcode but not one tuning row, so the heal-spray recipe is keyed by source unit and a scripted heal spray resolves per body.
- Trace, geometry, eligibility, timing and state: identical to the Monk's (caster-origin dummy, healed-unit-centered spray, independent effect mask, 0.1 s attack resume, no new persistent state).

## Brew Hut / Ironpaw Militia

- Identity/source: runtime r177; `n03F` (`npgr`) produces `n03G` in the second slot of the top row and upgrades to the Fighting Tavern. Protected life, armor, weapon and (absent) mana come from the retained catalogs; the ordinary Normal melee weapon targets ground units and structures. Corpse, collision, classification, production, construction/repair/economy and upgrade data consume the retained catalogs.
- Complete inventory/control flow: three abilities, none with a script consumer. `A0G3` (`ACev`) is the same native Evasion row the Harpy uses (shared source key; chance from the retained `Chance to Evade`). `A0GS` (`Assk`, "Drunk resistance") is the native Hardened Skin with a map-overridden mask of air/ground enemies: the stock row's `enemy,ally` mask does not name an attacker class either, so the mask is not an attacker filter and the shared always-on rule applies (100% chance, retained ignored damage, no minimum). `A0GQ` (`ACct`, "Drunk") is a Critical Strike with a retained 20% chance and a damage multiplier **below one**, the native near-miss: the weapon is scaled down to the retained fraction before armor.
- Engine note: the shared critical-strike resolver only supported multipliers above one (its u16 subtraction would have overflowed). It now computes a signed delta, keeps "only the highest successful multiplier applies" across independent rolls, and flags a critical only when the delta is positive, so the near miss neither triggers critical-only consumers nor counts as a bonus.
- Known tooltip/object discrepancy: the tooltip says "10% to evade" and "20% near-miss", the object data supply the values above; the tooltip's "reduces incoming damage by 15" matches the retained ignored damage.
- State: none beyond ordinary evasion/proc rolls.

## Fighting Tavern / Ironpaw Guardian

- Identity/source: runtime r178; `n03K` (`npgr`) upgrades from the Brew Hut and produces `n03J` in the same root's upgrade slot (leading to the Temple of Ten Thousand Drinks). Protected life, armor, weapon and classification data come from the retained catalogs; the Normal melee weapon targets ground units and structures.
- Complete inventory/control flow: `A0HF` (`ACev`, Evasion), `A0H7` (`Assk`, hardened skin with its own retained ignored damage) and the shared Drunk row `A0GQ` (the Militia's near-miss, same tuning because it is one ability object) are object-data native. `A0HG` ("PAN: Whirlwind", `ACct`) is a Critical Strike row with all-zero fields, so it never acts natively; it is only the marker the script's damage listener checks.
- Scripted spell trace: `qP` installs the listener 0.1 s after start (constants: marker, probability, damage, radius). Trigger eligibility: a landed damage event of type 0 (attack damage) whose source holds the marker, then a uniform roll that passes with probability `0.20` (the comparison is inclusive; evaded attacks produce no damage event and never roll). Effect origin: the *damaged target's position* (a building's footprint centre when the target is a structure) — not the attacker. Effect eligibility is independent of the trigger: alive enemy units that are combat sappers and not flying within the retained radius, including the damaged unit itself; invulnerable units cannot be damaged. Each receives the retained damage as universal damage with the shared spell armor-type table and spell defenses, credited to the attacker. No resources, cooldown, delay or persistent state; the Spin animation is presentation. A killing blow still spins because the listener runs on the landed damage event.
- Known tooltip/object/script discrepancies: the tooltip says 150 damage and "Wasted 30%" near-miss; the script constant is 175 and the Drunk row is 20%. Runtime values win.
- Engine note: a new triggered attack effect (`Whirlwind`) shares the orb-proc roll path; it is hashed in the canonical and content identities.

## Temple of Ten Thousand Drinks / Drunken Brewmaster

- Identity/source: runtime r179; `n03P` (`npgr`, legendary) upgrades from the Fighting Tavern and produces `n03O`, the root's final upgrade. Protected life, armor, the Hero-type melee weapon (ground and structure targets), classifications, production, construction/repair/economy and the legendary production relationship consume the retained catalogs.
- Complete inventory/control flow: `A0HF` (shared Evasion row), `A0HC` (`Assk`, hardened skin with the largest retained ignored damage), `A0HA` (`ACct`, "Drunk 3": a 50% near-miss row with a retained multiplier below one, resolved by the shared critical resolver), and `A0HH` (`ACac`, "Brewcommand Aura", a native friendly damage aura sharing the `AIar` data layout: percent bonus, melee and ranged flags, flat bonus). The aura's mask is friendly air/ground units and self; the radius is the retained area and the bonus is the retained percentage. The legendary markers `A06V` (`Asph`, zero attachments), `A07H` (`ANcl`), `A070` (`Amgl`) and the legendary `A0AH` spell-resistance row are the shared, already audited hidden/classification rows; their bindings are reused without a second copy of any value. No script grant, proxy or delayed callback exists on this body.
- Engine note: `ACac` is accepted as a native damage-aura base only because its audited fields are the same ones the `AIar` projection reads; every other aura base is still rejected.
- State: none beyond ordinary proc rolls and aura membership.

## Temple of the Wandering Spark / Echofoot Mystic

- Identity/source: runtime r180; `n03H` (`npgr`) produces `n03I` in the third slot of the top row and has no upgrade. Protected life, armor, movement, the Magic missile weapon (air, ground and structures) and classifications come from the retained catalogs; the unit has no mana pool.
- Complete inventory/control flow: the only object ability is `A0H4` (`ANcl`, "Echo Blink", zero visibility); it never casts. It is the cooldown carrier and presence marker for the shared tower/unit damage listener (`DamageListener_addListener_doAfter_ThunderpawSpire…`, which also serves unrelated towers and units) and the `fJ` death handler. The remnant unit `n03R` carries `Aloc` and `A0HD` (`Amin`, "Static Remnant Explosion").
- Scripted spell trace: trigger eligibility — any damage event whose target is a living Mystic, whose source is a living combat sapper strictly closer than the retained range (`< 62500` squared), with `A0H4` off cooldown; the script runs before the damage is committed, so a lethal hit still blinks and spawns the remnant. Approach/geometry — none. Effect origin: the remnant is created at the Mystic's position (owner, facing), then the Mystic is placed the retained distance along the line to its own castle (`SetUnitPosition`; the engine pulls the destination back cell by cell to the first point legal for the bearer's circle in its own navigation component) and re-ordered to attack (target and locks cleared). The marker cooldown is restarted with the script's retained value, **not** the protected 20 s ability cooldown. Effect eligibility is independent: the remnant detonates when an armed (after the retained activation delay) enemy ground unit comes within the retained `Rng1` radius, or when its 60 s timed life ends; the death handler then deals the retained magic damage to every enemy combat sapper within the retained radius that is not invulnerable, spell immune, carrying the tentacle marker `A08H` or the excluded wisp type. Damage uses the normal attack-type table without armor points, then spell defenses (a deterministic reading of `ATTACK_TYPE_NORMAL` + `DAMAGE_TYPE_MAGIC`); kill credit is the Mystic's. Two Mystic remnants do not interact.
- Known tooltip/object/script discrepancies: the importer labels the excluded recipient type `h06C`, but the script literal is `1747990082` (`h06B`, the Wisp); the literal governs. The tooltip's "enemy proximity" is `Amin` with a retained range; `Amin` has no retained trigger mask, so ground enemies are used (land mines ignore flyers). The protected cooldown (20 s) differs from the script's 15 s. Only damage routed through the shared weapon-damage path triggers the blink; damage from other native spell paths and from buildings does not.
- State/serialization: `echo_step_ready_tick` (status), the authoritative `EchoRemnant` action (position, owner, creation/arming/expiry ticks, profile) and the phase-local blink destination, with canonical tags 40/41; snapshot schema 108 and checksum schema 105.
- Presentation: remnant art and the blink effects are not yet presented by the client; the authoritative remnant state retains position/owner/created tick so a presentation can follow without changing gameplay.

## Pandaren Siege Workshop / Brewshock Catapult

- Identity/source: runtime r181; `n03N` (`npgr`) produces `o00H` (`ocat`) in the last slot of the top row and has no upgrade. Protected life, armor, the Siege artillery weapon (ground and structures, retained splash bands and projectile speed) and the retained mana pool (maximum and regeneration, no starting mana) come from the catalogs. The second, structure-only `msplash` weapon is disabled and unavailable.
- Complete inventory/control flow: the sole ability is `A0H9` (`AEpa`, "Whirlstone Brew"), the unit's default-active ability (`udaa`), with no script consumer. Native Poison Arrows is an autocast attack orb: its extra damage is added to the weapon, its mask is air/ground organic units (so structures and mechanical units neither pay nor receive it) and its mana cost is the protected value. Its poison payload fields (damage per second, speed and attack-speed factors, stacking) are all zero, so no poison state exists; the retained one-second duration therefore has no effect.
- Engine note: the shared mana attack orb replaced the weapon's delivery with a homing missile and its own splash. A new `preserve_delivery` flag lets this orb add only its payload to the artillery weapon, keeping its ballistic flight and splash bands; `organic_only` honors the native `organic` token. The orb bonus is part of the attack damage, so splash falloff scales it exactly as the existing orb consumers do.
- Known tooltip/object discrepancies: the tooltip says the bonus hits "enemy units in 300 AoE" and fires "at full mana"; the object row's `Area1` is not read by native Poison Arrows (recorded as unused provenance) and the cost (50) is below the 60 mana pool, so the orb fires whenever mana is at least the cost. Runtime object data wins.
- State: none beyond ordinary mana and attack rolls.

## Cloud Hangar / Cloud Ship

- Identity/source: runtime r182; `n03Q` (`npgr`) produces `h07S` in the first slot of the second row and has no upgrade. Protected life, armor and the Magic missile weapon (air, ground and structures) come from the catalogs; the flying body's movement, collision, corpse and classifications are the retained flyer data. The second Pierce weapon (air only) is disabled and unavailable.
- Complete inventory/control flow: `A0GV` (`AIsr`) is the shared native spell-damage reduction row (the retained factor); `A0GZ` (`Aroc`, "Cloud Ship Multishot") is native Barrage and has no script consumer. The shared Barrage rule applies: extra independent homing missiles use the ordinary weapon damage and independent evasion, the retained Efk3 count follows the audited `Efk3 + 1` additional-target interpretation (so the primary and two more targets, matching the tooltip), and Efk1/Efk2 are not a damage budget.
- Mask interpretation: the retained Barrage target mask is the enemy relation alone, with no physical class. The audited carrier rule rejected class-less masks; Barrage launches ordinary weapon missiles, so an enemy-only mask now leaves the class to the firing weapon (every class, intersected with the weapon's own mask at launch). Other carrier consumers (the Obelisk cleanse) keep the strict rule.
- State: the already-persisted in-flight native bolt state; no new shape. The carrier projection was regenerated for the new Barrage source.
