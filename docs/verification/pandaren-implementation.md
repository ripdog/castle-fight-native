# Pandaren implementation

Retained Castle Fight 9.27/r1 extraction tree: `8ea806dca331ff254995e94e6f0baf225a14bf10`. Builder `X07P`, registration `WK`, and the resolved `ubpx`/`ubpy` build-card coordinates define implementation order (an absent coordinate on a map-authored `npgr`/`hgtw`/`hhou` building is the stock origin). Complete each root and its entire upgrade chain before moving right, then the next row. Only completed entities become buildable. The order is Bamboo Dojo → Sagepaw Sanctum; Brew Hut → Fighting Tavern → Temple of Ten Thousand Drinks; Temple of the Wandering Spark; Pandaren Siege Workshop; Cloud Hangar; Jade Shrine; Withering Hall; Thunderpaw Spire; Poof Tower (already promoted as a shared tower); Celestial Chi Tower.

## Bamboo Dojo / Sagepaw Monk

- Identity/source: runtime r175; `n03D` (`npgr`) produces `n03E` in the top-left slot and upgrades to the Sagepaw Sanctum. Protected life, armor, movement, attack damage/dice/cooldown/range and the Monk's mana pool supersede static sentinels; the ordinary Magic missile weapon targets ground, air and structures and the second weapon is disabled. Corpse (raisable, decaying organic), collision, classification, production, construction/repair/economy and upgrade data consume the retained catalogs.
- Complete inventory/control flow: the only ability is `A0GN` (`Ahea`, "PAN: Panda Monk Heal"). `NI` registers it with target mode 7 (any ally) and the closure `MonkHeal` — the same autonomous native Heal order the Faerie Dragon uses, with protected mana and cooldown. Its mask is air/ground friendly organic non-ancient units, vulnerable or invulnerable, self included. No other script grant, proxy or hidden marker exists on this body.
- Scripted spell trace: trigger eligibility — wounded friendly unit within the native Heal range (the shared `WoundedFriendlyUnit` policy). Approach — native cast range. Effect origin — the native heal lands on the target; the script then spawns a free recycled dummy at the *caster* and orders the dummy's `healingspray` (`A0GP`, `ANhs`) at the *healed unit's* position. Effect eligibility is independent of the trigger: the spray's own mask is friendly air/ground units (mechanical and non-organic units included, the caster included), vulnerable only; spell-immune friends are healed. Timing — the caster's attack order resumes 0.1 s after the cast (the retained callback); the spray is a channel on a dummy that is returned after the closure's 2.0 s lifetime, so it outlives the caster. Resources — the parent's mana/cooldown only; the child dummy is protected-free.
- Healing Spray interpretation: the retained fields give wave count, interval, per-wave amount, per-wave total cap and missile count. Native evidence is limited to [the editor note](https://github.com/Cokemonkey11/wc3-ability-doc/blob/main/sources/screwthetrees-wc3-editor-ability-insight-document/2023-11-14.md) that Healing Spray is a Cluster Rockets copy with reversed damage. The engine therefore reuses the Blizzard-wave cadence: every wave heals every eligible unit in the area by the retained amount, the per-wave total is shared proportionally when the retained cap would be exceeded, and the first wave lands one retained interval after the cast. These cadence choices are deterministic interpretations without a Warcraft runtime oracle; the missile count is cosmetic.
- State/serialization: the spray is authoritative `NativeAction::HealingSpray` state (canonical hash tag 40, serde-serialized with the other native actions); the heal profile gained an optional `spray` (hashed). A scripted heal spray is resolved per body, because each body's script casts its own child ability.
- Presentation: no new gameplay-relevant presentation state; heal and spray art remain source-owned. Pandaren becomes selectable with this completed root; later roots and upgrades remain unavailable until their own mechanics are verified.

## Sagepaw Sanctum / Sagepaw Soulkeeper

- Identity/source: runtime r176; `n03S` (`npgr`) upgrades from the Bamboo Dojo and produces `n03T`. Protected life, armor, movement, weapon and mana pool come from the retained catalogs; the weapon, corpse, classification, production and upgrade data are the same classes as the Monk's.
- Complete inventory/control flow: `A0GN` again, registered by `NI` with the second closure (`MonkHeal1`). The native Heal fields are identical to the Monk's; the script's child is `A0HI` ("Healing Spray 2", `ANhs`) with its own retained amount, per-wave cap, missile count and area. The two bodies share one ability rawcode but not one tuning row, so the heal-spray recipe is keyed by source unit and a scripted heal spray resolves per body.
- Trace, geometry, eligibility, timing and state: identical to the Monk's (caster-origin dummy, healed-unit-centered spray, independent effect mask, 0.1 s attack resume, no new persistent state).
