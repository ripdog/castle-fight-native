# Nature implementation

Retained Castle Fight 9.27/r1 extraction tree: `8ea806dca331ff254995e94e6f0baf225a14bf10`. Builder `X01A` ("Nature Builder", `uabi` `A06E,Aeth,AInv,A005,A001,Ahrp,Avul`), registration `IK` and the resolved `ubpx`/`ubpy` build-card coordinates define implementation order. Complete each root and its entire upgrade chain before moving right, then the next row. Only completed entities become buildable. The order is Spider Egg Clutch → Spider Egg Nest → Spider Egg Hatchery; Furbolg Hut → Furbolg Abode, then its second branch Enigma; Ancient of Growth → Ancient of Life → Ancient of Eternity; Ancient of Slumber → Ancient of Hibernation; Emerald Dragon Roost; Monolith; Ancient Guardian; Ancient of Gale; Ancient Protector; Ancient of Wonders; the shared Treasure Box (already promoted). (`Aeth`, `AInv`, `Ahrp`, `Avul` and the build-menu abilities are the shared builder body already used by every promoted race.)
