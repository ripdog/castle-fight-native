# Castle item system (map 9.27, retained revision r1)

Evidence layer: `crates/sim/data/castle-fight/9.27/items-r1.json`, generated by
`tools/wc3-map/project_items.py` (`--check` reproduces it). Runtime: `crates/sim/src/simulation/items.rs`
with mechanic tests in `items/tests.rs`.

## Implemented

- WC3-style six-slot inventory per builder: use, move, swap, give, drop, pick up; charges and shared
  cooldown groups; four Blast Staffs combine into a Multi Blast Staff.
- Ground items as entities; walk-then-act orders (`PendingItemOrder`), cancelled by a new order.
- Castle shop: per-team stock, start delay, restock interval, one-second button cooldown, powerups
  consumed on purchase. Spellbook layout and button cell come from the projection.
- All ten shop items: Rune of Repair, Bassline Generator, Scroll of Stone, Blast Staff (and Multi Blast
  upgrade), Bass Drums, Cheese, Orb of Lightning, Scroll of Speed, Double Damage, Quad Damage.
- Round restart restores the tick-zero item state: shops closed with fresh stock timers, no team
  buffs or pending impacts, builders back to empty inventories, ground item entities discarded.

## Evidence gaps / deliberate approximations

| Area | Status |
| --- | --- |
| Pickup / drop / give range | Engine default 150 wu; not present in extracted data. |
| Buyer unit selection | Purchase is made by the issuing builder; the map's selection rule is not traced. |
| Stock start base | Stock opens at round start + authored start delay. |
| Filler button (AIsr, list index 8) | Occupies its cell in the layout but is not rendered. |
| Item HP / ground destruction | Not modelled. |
| Movement speed cap for Speed scroll | Not modelled beyond the authored speed bonus. |
| I000 gold pickup | Not implemented. |
| Hero / divine damage tooltip modifiers | Not modelled (tooltip-only evidence). |
| Cheese game modes | Cheese adds one legendary slot. The script instead refunds the 1750 gold when legendary mode (flag GGb) is off or no-cheese mode (flag HGb) is on; the engine has no such lobby modes, so the slot path always applies. |
| Scroll cooldowns | No cooldown is authored, so none is applied. |
| Blast Staff missile | Damage lands after the authored flight time at the target. Presentation shows the ability's extracted missile art flying to the target; the missile does not retarget if the target dies. |
| Time conversion | `seconds_to_ticks` goes through f64; values are authored in whole or tenth seconds. |
| Hotkeys | Inventory uses WC3 default numpad 7/8/4/5/1/2 (not extracted). Shop opens by click only: R conflicts with Repair autocast. |
