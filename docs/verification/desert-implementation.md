# Desert implementation

Retained Castle Fight 9.27/r1 extraction tree: `8ea806dca331ff254995e94e6f0baf225a14bf10`. Builder `X078`, registration `qK` and the resolved `ubpx`/`ubpy` build-card coordinates define implementation order (an absent coordinate on a map-authored `npgr` building is the stock origin). Complete each root and its entire upgrade chain before moving right, then the next row. Only completed entities become buildable. The order is Quillboar Yard → Razormane Abode; Gnoll Tent → Fire Gnoll Hut; Harpy Nest → Nest of Harpy Witch → Nest of Harpy Matriarch; Sandkin Burrow → Monstrous Sandkin Burrow; Ogre Den → Den of the Ogre Lord; Salamander Hatchery; Sacred Peyote; Beacon of the Oasis; Ballista Tower; Temple of Storm; shared Treasure Box.

## Quillboar Yard / Quillboar

- Identity/source: runtime r152; `n036` (`npgr`) produces `n02V` (`nqb1`) in the top-left slot. Protected body life, armor, attack damage/dice, cooldown and range supersede static sentinels. The ordinary Pierce weapon (ground and structure targets, no air), acquisition/collision, regeneration, raisable/decaying organic corpse, sapper/ward classification, production, construction/repair/economy and upgrade relationship consume retained versioned catalogs. The second weapon slot is disabled. The building inventory is empty and carries only the `Mechanical` classification.
- Complete inventory/control flow: the sole body ability is `A0G6` (`AUts`). Its returned-damage factor (map-overridden), received-damage factor and bonus armor come from the resolved ability row; it is the same intrinsic passive class as the existing Spiked Shell recipe, with no cast, resources, buff art or delayed state. Literal references close to object registration, protected statistics, `xO` combat metadata and the `qK` race registration; no script grant, proxy or hidden marker exists. The shared `A0CV` assassination marker is not present on this body.
- Engine note: Desert buildings derive from `npgr`, whose retained overrides record only non-origin build-card components. The content loader now resolves an absent component of an authored building button to zero instead of rejecting the building; units keep their existing explicit-pair rule.
- Presentation/state: no new authoritative state or serialized shape. Desert becomes selectable with this completed root; incomplete upgrades and later roots remain unavailable until their own mechanics are verified.

## Razormane Abode / Razormane

- Identity/source: runtime r154; `n037` (`npgr`) upgrades from `n036` and produces `n02U` (`nrzt`) in the same root's upgrade slot. Protected body life, armor, attack damage/dice, cooldown and range supersede static sentinels. The ordinary Pierce weapon (ground and structure targets, no air), mana pool (maximum, starting, regeneration), acquisition/collision, regeneration, raisable/decaying organic corpse, sapper/ward classification, production, construction/repair/economy and upgrade relationship consume retained versioned catalogs. The second weapon is disabled; the building inventory is empty.
- Complete inventory/control flow: `A0G7` (`AUts`) is the same intrinsic returned-damage passive as the Quillboar's with its own retained factor. `A0GL` (`AEfk`) is registered object data whose only script consumer is `handleFanOfKnives`, called by the global per-unit damage runtime (`EVENT_UNIT_DAMAGED`, installed for every combat sapper) with the *damaged* unit. The listener requires the Razormane body type, `BlzGetEventDamageType() == DAMAGE_TYPE_NORMAL`, a positive ability level, zero remaining cooldown and current mana at least the native cost; it then issues the immediate `fanofknives` order and `orderCodeAttack` for the same unit with no delay. The importer reconciles those predicates, the retained effective cooldown/mana cost/area/mask and the native damage fields before emitting the profile.
- Trigger vs effect: trigger eligibility is "the Razormane itself took ordinary weapon damage" (authoritative `RetaliationState` of the previous completed tick, shared with ally defense); there is no unit target, approach geometry or range. The effect origin is the caster. Effect eligibility is independent: living hostile air/ground *units* in the retained area that are organic (not mechanical), not invulnerable, not spell immune and not Locust. Structures and wards are not hit. Damage is native spell damage (spell armor-type table and Defend reduction); per-target damage is the retained value unless that times the number of recipients exceeds the retained total cap, in which case the cap is divided evenly (floor). A nonzero retained target limit would keep the nearest recipients; this body's is unlimited.
- Resources/timing: mana is committed at cast and the cooldown starts at the cast; the ordinary cast action (unit cast point/backswing) applies because the unit issues its own order. The script gate and the order are one callback in WC3; the engine evaluates the trigger at the start of the next tick, so the order can lag by the tick granularity. After the cast the unit resumes ordinary combat. A stunned, frozen or dead Razormane cannot cast.
- Known tooltip/object/script discrepancies: the ability is a manual-looking Warden spell that the script also issues from any normal-type damage event; script-authored `UnitDamageTarget` calls that use the same damage type (for example other units' death explosions) are not modeled as triggers, only ordinary weapon impacts that mark retaliation. Native spell damage uses a different WC3 damage type and is correctly excluded.
- State/serialization: the cast reuses existing mana/cooldown/cast-sequence state; the new `FanOfKnives` ability effect and `AttackDamageTrigger` policy are included in canonical hashing, content identity hashing and the snapshot schema (v99).

## Gnoll Tent / Gnoll

- Identity/source: runtime r156; `n02P` (`npgr`) produces `n02S` (`ngna`) in the second slot of the top row, upgrading to the Fire Gnoll Hut. Protected life, armor, movement, attack damage/dice and range supersede static sentinels; the weapon cooldown is the static value. The single Normal missile weapon targets ground, structures and air; the second weapon is disabled. Acquisition/collision, regeneration, raisable/decaying organic corpse, sapper/ward classification, production, construction/repair/economy and upgrade relationship consume retained versioned catalogs.
- Complete inventory/control flow: `A0CV` is the shared hidden Channel marker. `A0G2` (`ACvs`, "Heavy Bolt") is registered object data with no script consumer: a poison whose retained mask is `air,ground` (no `organic` token, so mechanical bodies are slowed too), whose movement factor lives in `Datab` (resolved metadata labels `Poi2` movement and `Poi3` attack speed for every poison base; the shared importer had the two fields swapped for `ACvs`/`Aven`, which was invisible while those rows were symmetric) and whose retained damage is a sub-point `0.01` per second. The engine's health resolution is whole points, so that fraction is recorded in the tuning provenance as unrepresented rather than rounded in the profile: the effect is the retained 20% movement slow for the retained 2 seconds. `A0HM` ("Fowlhunter 2x", `ACct`) is a 100% critical strike restricted by its retained mask to air targets only, so it doubles damage against flyers and never procs on ground units or structures.
- Scripted retarget trace: the shared damage listener (`DamageListener_addListener_doAfter_ThunderpawSpire…`, which also serves unrelated towers) fires for every damage event whose recipient is a Gnoll or Fire Gnoll body. Trigger eligibility: the damage source is a flying unit. Effect: after a per-recipient throttle stamp is written (strictly more than the retained interval after the last stamp, initial stamp zero), the Gnoll receives an `attack` target order against the damage source; a refused order still consumes the interval. `checkForWrongOrder` exempts exactly this attack order for these two body types. The engine models the order as a direct personal-attacker engagement that replaces any current target and persists until the target stops being retainable (same sticky rules as retaliation); the stamp is authoritative status state. No cast, resource or delayed callback exists. `A0HK` ("DST: Gnolls auto") is a protected-field orphan: no inventory, script grant or registration references it, so nothing is installed.
- Corpse/classification behavior: ordinary organic raisable corpse; the sapper/ward classification is retained and distinct from target masks.
- State/serialization: new authoritative per-unit retarget stamp (canonical hash and snapshot schema v100); the poison profile gained an explicit `organic_only` flag (hashed, default true for existing rows) and the retarget rule list is part of the content identity hash.
